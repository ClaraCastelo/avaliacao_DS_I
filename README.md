Avaliação de 50 pessoas - Projeto em python

Utilizou loop para analisar a avaliação de 50 pessoas

   Avalações possiveis: 
  1 - ruim
  2 - bom 
  3 - excelente 
   
• Como executar o programa:
O usuario deve insirir os nomes, idades e avaliação. Após 50 pessoas, o programa informa quantos "ruins" e "excelentes" foram contabilizados.
